World Bank · DebtPriority 1

International Debt Statistics ↗

Yes—strongly relevant. IDS supplies annual external debt stocks and flows, debt-service measures, creditor/debtor composition and ratios for reporting low- and middle-income countries. It enriches debt sustainability, external financing and interest-burden context.

Not a complete public-debt or fiscal dataset: coverage centers on external debt reported through the Debtor Reporting System. Pair with IMF fiscal balances and domestic/public-sector debt data.
World Bank API docs ↗ · IDS DataBank ↗
OECD · RevenuePriority 1

Revenue Statistics in Africa SDMX API ↗

Official SDMX REST API offers comparable tax and non-tax revenue series, shares, and country breakdowns. Useful for interactive revenue composition and tax-to-GDP charts.

Current displayed series are updated on OECD’s schedule; present reference year and country coverage beside every chart.
OECD API guide ↗
IMF · Fiscal / macroPriority 1

IMF Data API + Fiscal Monitor ↗

IMF Data exposes SDMX 2.1 and 3.0 APIs. Fiscal Monitor and WEO provide fiscal aggregates, debt and projections; DataMapper has a separate JSON API for selected series.

Fiscal Monitor estimates may differ from national or other IMF datasets; projections and source conventions must be labeled.
DataMapper API docs ↗ · Fiscal Monitor series ↗
World Bank · MacroPriority 2

World Bank Indicators API v2 ↗

Public, keyless JSON API covering WDI and 45+ databases. Use it for GDP, inflation, growth and related denominators that help contextualise fiscal series.

IDS is available through the same API family. Confirm source, indicator metadata, update lag and country-specific missing values.

How to use this desk

Evidence with context

Track performance, not just ratios

Tax-to-GDP is one lens. Revenue composition, non-tax and resource revenue, volatility, tax expenditures, compliance, fiscal balances, debt service and spending quality explain more of a country’s fiscal position.

Read the metadata

Coverage, reporting years, revisions, resource dependence and national definitions vary. A regional average can conceal large country differences. Check the original tables before making comparisons.

Pair scholarship with institutions

Peer-reviewed studies help test causal claims and explain political economy; institutional datasets and outlooks provide broader cross-country measurement and policy context.

A living research collection

This initial collection is curated, not exhaustive or automatically updated. New editions and country-level budget documents should be added as they are published.
